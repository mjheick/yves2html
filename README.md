# yves2html
Convert a [YouVersion Bible[(https://www.youversion.com) yves file to HTML.

# build
clone archive and run make.
```
make
```

# Running
Run with yves format as the parameter. It'll make a new file with .html as an appended extension.
```
$ ./yves2html 1.yves
> Creating 1.yves.html
done
```
